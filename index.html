Problem

AI 워커에게 일을 시키려면
결국 컴퓨터 앞에 앉아야 합니다

Antigravity, Codex, Claude Code — 셋 다 PC에서 돕니다. 자리를 뜨는 순간 지시도, 확인도 끊깁니다. 원격 데스크톱은 무겁고, 터미널 공유는 폰에서 쓸 물건이 아닙니다.

🚶

자리를 뜨면 끊긴다

외출·이동·회의 중에는 돌아가는 작업을 볼 수도, 다음 지시를 줄 수도 없다.

🧩

워커마다 창이 다르다

IDE 대화창, 터미널 두 개. 폰에서 셋을 한 화면에 모을 방법이 없었다.

🔌

설정이 무겁다

포트 포워딩, 고정 IP, VPN, 앱 설치. PC를 바꾸면 처음부터 다시.

How it works

PC에서 한 번, 폰에서 한 번 —
그 뒤로는 지시하고 결과를 받는 일만

스타터 킷 폴더를 더블 클릭하면 PC가 스스로 길을 열고 이름표를 붙입니다. 폰은 늘 같은 주소를 열기만 하면 됩니다.

PC에서 더블 클릭

실행기가 콘솔 서버를 띄우고, 내장 cloudflared로 공개 https 주소를 받아 기기 장부에 등록합니다. 60초마다 생존 신고.

폰에서 북마크 열기

고정 허브가 장부를 읽어 켜진 PC로 보내 줍니다. 1대면 0.5초 자동 직통, 여러 대면 PC 카드를 골라 터치.

지시하고 결과 받기

탭을 고르고 지시. Antigravity는 PC 대화창이 그대로 비치고, Codex·Claude는 CLI가 돌아 결과를 돌려줍니다. 긴급 정지는 언제나.

Architecture

클라우드는 길만 열어 주고,
실행과 파일은 전부 PC 안에

허브와 장부가 아는 것은 "어느 PC가 켜져 있고 주소가 무엇인가"뿐입니다. 대화도, 업로드한 파일도, 워커가 만든 결과물도 클라우드에는 남지 않습니다.

Workers

메인 하나, 서브 둘 — 일에 맞는 워커를 골라 지시

셋 다 PC 안에서 실행됩니다. 폰은 지시와 확인만 합니다.

🪐

Antigravity 메인

총괄 지휘·통합 코딩. PC의 IDE 대화창이 폰에 실시간으로 그대로 비친다. 폰의 지시는 파일 큐로 들어가 워커를 깨운다.

⚡

Codex CLI 서브

고속 스크립트·파일 수정. 무인 백그라운드 데몬으로 돌고, 결과는 messages 파일에 남아 폰이 폴링으로 가져간다.

🤖

Claude Code CLI 서브

심층 분석·복합 리팩터링. Codex와 같은 방식의 무인 데몬. 사진·파일을 올리면 자동 분석 프롬프트가 붙는다.

Console

탭 4개, 그리고 긴급 정지

🪐 Antigravity

대화창 미러 + 지시 입력. 3줄 요약·한 줄 결론·계속 진행 칩.

⚡ Codex

지시 → 실행 → 결과. 상태 라벨(작업 중/대기)과 전체 히스토리.

🤖 Claude Code

Codex와 같은 레이아웃. 사진·파일 업로드 후 분석 지시.

📁 파일·시스템

호스트·가동시간·RAM, 파일 목록·검색·편집·저장. 작업 폴더 밖은 차단.

공통 — 사진·파일 업로드, 긴급 정지(실행 중인 워커 프로세스 트리를 즉시 종료), 상단 [⇄ PC 전환]으로 다른 PC로 이동.

Design principles

단순해서 잘 안 죽고, 클라우드에 남기지 않는다

🔑

PIN 한 번, 이후 토큰

첫 접속에 PIN을 넣으면 세션 토큰이 발급되고 모든 API 호출에 자동으로 붙는다. 토큰 없는 요청은 전부 거절.

☁️

클라우드에는 주소만

허브와 장부는 "어느 PC가 켜져 있고 주소가 무엇인가"만 안다. 대화·파일·결과물은 PC 밖으로 나가지 않는다.

🔁

WebSocket 없이 폴링

1.2~1.5초 폴링과 JSON 파일 큐. 부품이 적어 끊겨도 스스로 돌아온다.

📦

폴더 하나가 전부

cloudflared·ttyd 실행 파일 내장. 폴더를 복사해 어느 PC, 어느 프로젝트에 붙여도 그대로 동작.

Starter kit

폴더 하나, 더블 클릭 한 번

실행기·서버·브릿지·터널 엔진과 실행 파일 2개가 한 폴더에 들어 있습니다. 소스와 사용법은 GitHub에서.
